# Export-ReportToHtml

**Prüfstatus: Ungeprüft**

Exportiert einen Gerätestatus-Bericht als HTML.

<!-- library-status:start -->
    Prüfstatus: Ungeprüft

    Erstellt eine einfache HTML-Datei mit einer Tabelle aller Geräte und deren Status.
